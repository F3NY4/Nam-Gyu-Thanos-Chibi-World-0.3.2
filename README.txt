NAM GYU × THANOS — CHIBI WORLD 0.3.2
Android-first 2-player multiplayer

Что нового в 0.3.2
- Настоящая квартира как отдельная локация без перезагрузки страницы.
- Переходы Сеул / Квартира / Парк / Кафе через верхнюю панель.
- Отдельные карты и коллизии для каждой локации.
- Мебель: диван, TV, кухня, стол, кровать, ванна, шкаф, столики кафе, лавочки и т.д.
- Совместный сон: оба игрока должны находиться у кровати в квартире.
- Готовка: возле кухонной стойки.
- Душ/ванна: отдельная зона ванной комнаты; одежда переключается на bath.
- Сменная одежда: обычная, сон, жара, холод; sleep/bath применяются автоматически для соответствующих действий.
- Живые совместные анимации: объятие, поцелуй, high-five, танец, сон.
- Чат остаётся свободным, русский/английский, без встроенного фильтра мата.
- Смена дня/заката/ночи сохраняется в комнате.
- Состояние комнаты и история чата сохраняются в памяти текущего сервера; локальные настройки сохраняются на устройстве.
- Ограничение комнаты: 2 игрока.

Как запустить
1. Нужен Node.js 18+.
2. В этой папке выполнить: npm install
3. Затем: npm start
4. Открыть http://<адрес-сервера>:3000 на двух телефонах.
5. Ввести одинаковое имя комнаты, например couple.
6. Один выбирает Нам Гю, второй — Таноса.

Для игры через интернет
- Размести папку nggame на небольшом Node.js cloud server.
- Сервер должен открыть порт через переменную PORT.
- Телефонам ПК не нужен: они подключаются браузером к HTTPS/WSS адресу сервера.

Графика
- 2D Canvas, без тяжёлого 3D.
- assets/chibi-sprite-sheet.png — сгенерированный chibi reference/sprite sheet.
- Мир рисуется процедурно, чтобы не тянуть тяжёлые ассеты на Android.
